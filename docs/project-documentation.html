1. Project Overview

SecureConfigAI is a security configuration analysis platform that collects device and security configuration data, checks it against security rules, scores the device posture, and presents findings, risk levels, AI explanations, and recommended remediation steps.

The application works as a single unified project and does not use separate v1/v2/v3 folders or duplicate codebases. The design document is treated as a roadmap, while the implementation itself remains one coherent project.

Core Purpose

  • Detect device information and scan context
  • Collect security-related configuration
  • Analyze findings using deterministic rule checks
  • Calculate a risk/security score
  • Generate AI explanations and recommendations
  • Show trends, history, and reporting data

Key Technologies

  • Frontend: React + TypeScript + Vite
  • Backend: FastAPI + SQLAlchemy + SQLite
  • Scanner: Python-based local security collector
  • AI: OpenAI-compatible / DeepSeek-compatible abstraction
  • Security logic: deterministic rule engine with scoring

4. Architecture

Request flow

  • User opens the dashboard
  • Frontend authenticates or creates a demo admin account
  • User clicks Start Security Scan
  • Frontend sends scan payload to backend
  • Backend detects/creates device
  • Local scanner collects configuration
  • Backend normalizes and analyzes the data
  • Findings are stored and scored
  • AI explanation and recommendation APIs can be called
  • Dashboard renders summary, findings, categories, score, and actions

Core rule

Deterministic security checks remain the source of truth for findings. AI is used to explain and prioritize results, not to invent findings or fake configuration values.

5. Runtime Workflow

  1. Frontend loads dashboard and auto-logs in to the demo session.
  2. One-click scan uses the existing backend scan service and real scan payload.
  3. Backend calls the scanner to gather local configuration.
  4. Normalized results are converted into security findings.
  5. Scan result model calculates security score, risk level, and counts.
  6. Findings are shown in the UI by severity and category.
  7. AI APIs explain findings and generate remediation guidance when a funded provider is available.
  8. Trend/history and comparison data are read from stored scan results.

9. Security and Privacy Notes

  • Only security-related configuration is collected, not private personal files or data.
  • Passwords and sensitive personal documents are not collected by design.
  • Device detection is limited to system/security-relevant information such as hostname, OS, version, build, and device metadata.
  • AI guidance is grounded in actual scan results and should not invent findings.

10. Summary

The final SecureConfigAI project is a single, unified application that combines a modern React dashboard, a FastAPI backend, a Python scanner, a SQLite database, and AI-powered explanations and recommendations. It is structured around a real security-analysis workflow:

Scan → Collect configuration → Normalize → Analyze → Score → Findings → AI explanation → Recommendations → Report/History

The project is designed to run locally in a development environment and to remain coherent as one product rather than separate versioned copies.
